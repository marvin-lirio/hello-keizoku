# Hello Keizoku

The starting point of my **Keizoku** development journey — an ongoing effort focused on building technical skills through consistent, hands-on development.

**Keizoku (継続)** represents continuity and persistence: learning by continuing to build, test, break, improve, and repeat.

## Purpose

This repository was created as a practical environment for developing and reinforcing skills across software development, quality engineering, automation, and DevOps.

The focus is not on presenting myself as a finished software developer. Instead, these projects document the progression from my existing background in **quality engineering and technical compliance** toward broader technical development capabilities.

Projects and exercises are used to practice areas including:

- HTML, CSS, and JavaScript
- Git and GitHub workflows
- Software development fundamentals
- Debugging and troubleshooting
- Testing and quality engineering
- Automation
- DevOps concepts and workflows
- AI-assisted development
- Iterative application development

## Learning Through Building

The Keizoku approach emphasizes practical development over passive learning.

Concepts are applied through working projects where features are implemented, tested, reviewed, refined, and occasionally rebuilt as my understanding improves.

AI tools are used as development accelerators for research, implementation, debugging, and code review. The goal is not simply to generate working code, but to understand the implementation, validate its behavior, and take responsibility for the final result.

> **AI accelerates the code. I own the outcome.**

## Status

Keizoku is an ongoing learning initiative. Projects in this repository may evolve as my technical skills and development practices continue to grow.
